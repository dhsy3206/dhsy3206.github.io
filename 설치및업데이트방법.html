DRM AI v9.7 설치 및 업데이트 방법

대상 DRM AI 배포본: DRM_AI_학교명_v9.7

대상 올인원 설치본: All-in-One_Assistant_for_teacher_v6.4_setup.exe

핵심 전제: 제공된 추가 기능 파일(.xlam)에는 API 설정이 이미 반영되어 있으며, 사용자 입장에서는 Gemini 기반 기능 사용을 기준으로 진행하면 됩니다.

  1. 작업 시작 전 엑셀을 반드시 종료합니다. (열려 있으면 설치/덮어쓰기 실패 가능)
  2. 처음 설치와 업데이트 절차는 다릅니다. 아래에서 본인 상황만 따라가세요.
  3. API는 이미 설정되어 있으므로, 사용자 임의로 API 관련 값을 변경하지 마세요. 문제가 있으면 학교 관리자에게 문의하세요.

0. 먼저 내 상황 선택

처음 설치 이 PC에서 DRM AI를 처음 쓰는 경우. 2번 절차를 끝까지 진행합니다.
업데이트 이미 사용 중이고 새 버전(v9.7)로 바꾸는 경우. 3번 절차만 진행합니다.

1. 공통 준비

  1. 열려 있는 모든 Excel 창과 Word 창을 종료합니다.
  2. 올인원은 제공된 All-in-One_Assistant_for_teacher_v6.4_setup.exe로 설치하고, DRM AI는 DRM_AI_학교명_v9.7.zip 파일을 내려받아 압축 해제합니다.
  3. 올인원 40번 기능(서식 생성, DRM AI설치)을 통해 C:\MyTrustedFiles 신뢰 폴더를 구성합니다. (이미 완료한 경우 생략 가능)
v9.7 기준 변경: DRM AI 사용을 위해 Acrobat Reader를 별도로 설치할 필요가 없습니다. PDF 관련 기능은 DRM AI 내부 처리 방식으로 사용할 수 있습니다.
처음 설치 사용자는 40번 기능 화면 하단의 설명서 보기 내용을 처음부터 끝까지 1회 수행하세요.
올인원 40번 기능(설치 도우미) 핵심 순서 - 설치/업데이트 공통
  1. 프롬프트 백업이 필요한 경우 먼저 백업합니다.
  2. 템플릿 백업이 필요한 경우 먼저 백업합니다.
  3. 모든 Excel 창을 종료한 뒤 추가 기능 적용을 진행합니다.
  4. .xlam 파일을 선택한 후 추가 기능 복사하기를 진행합니다.
  5. 추가 기능 버전에 맞는 Python 파일 설정을 완료합니다. (설치 위치: C:\MyTrustedFiles)

중요: 업데이트 전에는 1번(프롬프트)과 2번(템플릿) 백업 완료 여부를 먼저 확인하세요.

2. 처음 설치 절차 (최초 1회)

2-1) Python 64비트 설치

  1. 설치 파일: python-3.13.3-amd64 또는 python-3.13.9-amd64 권장
  2. 공식 다운로드: https://www.python.org/downloads/windows/
  3. 설치 첫 화면에서 Add python.exe to PATH를 반드시 체크 후 설치합니다.

2-2) CMD 창 열기 + Python 설치 확인 (윈도우 PC 초보자용)

  1. 키보드에서 Windows 키를 누른 뒤 cmd를 입력합니다.
  2. 검색 결과의 명령 프롬프트를 클릭합니다. (검은 창이 열리면 정상)
  3. 또는 Windows + R 키를 누르고 cmd 입력 후 Enter를 눌러도 됩니다.
  4. 검은 창에 깜빡이는 커서가 보이면 아래 명령을 한 줄씩 입력 후 Enter를 누릅니다.
CMD를 처음 쓰는 경우
까만 창이 CMD입니다. 명령을 입력한 뒤 Enter를 누르면 실행됩니다. 오타는 Backspace로 지우고 다시 입력하면 됩니다. 복사/붙여넣기는 Ctrl + C, Ctrl + V(또는 마우스 오른쪽 클릭)로 가능합니다. 
python --version
pip --version

정상 예시: Python 3.13.x, pip 25.x처럼 버전이 표시됩니다.

오류가 나오면
python is not recognized 또는 pip is not recognized 메시지가 나오면 Python 설치를 다시 실행하고 Add python.exe to PATH 체크 여부를 확인하세요.

2-3) CMD로 필수 패키지 설치 (초보자용)

  1. 아래 명령 전체를 드래그하여 복사합니다.
  2. CMD 창에서 마우스 오른쪽 클릭 또는 Ctrl + V로 붙여넣습니다.
  3. Enter 1번을 누르고, 설치가 끝나서 다시 줄 끝에 커서가 나타날 때까지 기다립니다.
  4. 중간에 영문 로그가 많이 출력되어도 정상입니다. 창을 닫지 말고 완료까지 기다리세요.
python -m pip install --upgrade pip && python -m pip install requests openai google-genai pillow PyMuPDF yt-dlp PySide6 && python -m pip show requests openai google-genai pillow PyMuPDF yt-dlp PySide6 && python -m pip install --upgrade google-auth google-auth-oauthlib google-api-python-client
성공 판정
설치 후 CMD 맨 아래에 다시 입력 가능한 커서가 보이고, 오류 문구 없이 종료되면 정상입니다. 같은 명령을 다시 실행해도 문제 없습니다.

설치 시간이 길 수 있습니다. 네트워크 상태에 따라 5~20분 정도 걸릴 수 있습니다.

2-4) 필수 파일 배치

배포 받은 업데이트 폴더의 Python 파일은 설치 위치: C:\MyTrustedFiles에만 복사(또는 덮어쓰기)합니다.

필수: 파일이 다른 폴더에 있으면 기능이 동작하지 않습니다. 반드시 C:\MyTrustedFiles 경로를 사용하세요.

2-5) 엑셀 추가 기능 활성화

  1. Excel 실행 → [파일] → [옵션] → [추가기능] 이동
  2. [찾아보기]로 배포받은 DRM_AI_학교명.xlam 선택
  3. 체크 후 활성화

이 단계는 보통 처음 설치 시 1회만 필요합니다.

2-6) 빠른 실행 도구 모음 등록(권장)

DRM AI 세부 설명서의 부록3: DRM AI 실행을 빠른 실행 도구 모음에 추가하기를 수행하면 메뉴 접근이 빨라집니다.

API 관련 안내
본 배포본은 API가 이미 설정되어 있으므로, 사용자는 일반적으로 API 입력/수정 없이 Gemini 기능을 사용하면 됩니다.

3. DRM AI 업데이트 절차

  1. 모든 Excel 창을 완전히 종료합니다.
  2. 40번 기능 1번 기준: 프롬프트 백업이 필요한 경우 먼저 백업합니다.
  3. 40번 기능 2번 기준: 템플릿 백업이 필요한 경우 먼저 백업합니다.
  4. DRM_AI_학교명_v9.7.zip 압축 해제 후 최신 파일을 기존 위치에 덮어쓰기합니다.
  5. 40번 기능에서 .xlam 파일을 선택한 뒤 추가 기능 복사하기를 실행합니다.
  6. Python 파일 덮어쓰기 + 패키지 업데이트(초보자용): 먼저 배포 받은 업데이트 폴더의 Python 파일을 설치 위치: C:\MyTrustedFiles에 덮어쓰기합니다. 그다음 CMD(명령 프롬프트) 창을 열고 아래 명령 전체를 한 번에 붙여넣은 뒤 Enter를 1번 누릅니다. 실행 중 영문 로그가 많이 보여도 정상이며, 다시 입력할 수 있는 커서가 나타날 때까지 기다리면 됩니다. 
    python -m pip install --upgrade pip && python -m pip install requests openai google-genai pillow PyMuPDF yt-dlp PySide6 && python -m pip show requests openai google-genai pillow PyMuPDF yt-dlp PySide6 && python -m pip install --upgrade google-auth google-auth-oauthlib google-api-python-client
    실행 후 패키지 버전 정보가 표시되고 오류 없이 끝나면 정상입니다. 오류가 나면 인터넷 연결을 확인한 뒤 같은 명령을 다시 실행하세요.
업데이트 핵심은 1번(프롬프트) + 2번(템플릿) 백업 완료 후 적용입니다. 백업 없이 덮어쓰면 개인 설정 복구가 어려울 수 있습니다.

업데이트 안내에서 추가 작업이 없더라도, 백업 확인(프롬프트/템플릿)은 매번 먼저 수행하세요.

5. 설치/업데이트 완료 확인 체크리스트

  • 엑셀 실행 시 DRM AI 탭/메뉴가 정상 표시된다.
  • Gemini 기반 기능 실행 시 인증 오류 없이 동작한다.
  • 필요한 py 파일이 C:\MyTrustedFiles에 존재한다.
  • 업데이트 전 사용자가 직접 개인 프롬프트/템플릿 백업본을 안전한 위치에 보관했고, 업데이트 후 개인 프롬프트/템플릿 백업본을 수동으로 정상 복원했는지 확인했다.

6. 자주 발생하는 실수와 해결

문제 해결
설치/덮어쓰기 중 파일 오류 엑셀/워드/올인원을 모두 종료한 뒤 다시 시도
python 명령 인식 안 됨 Python 재설치 후 Add python.exe to PATH 체크 확인
모듈 없음 오류 (예: PySide6, PyMuPDF) 2-3 패키지 설치 명령을 다시 실행
PDF 처리 중 보안/차단 문제 신뢰 폴더 설정(40번 기능/보안 설정)을 다시 수행
Gemini 실행 오류 API 임의 변경 여부 확인 후, 변경했다면 관리자 기본값으로 복구 요청
주의: 업데이트 시 API 설정값, 모델 설정, 관리자용 설정 메뉴를 임의로 수정하면 정상 동작이 깨질 수 있습니다.
