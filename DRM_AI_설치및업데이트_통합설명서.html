1. 내 상황 고르기 (2단계 선택)

딱 두 가지만 정하면 어디를 읽어야 할지 결정됩니다.

1단계 — 처음 설치인가요, 업데이트인가요?

처음 설치 이 PC에서 DRM AI를 처음 사용합니다. Python 설치부터 모두 필요합니다.
업데이트 이미 사용 중이고 새 버전으로 교체합니다. 먼저 개인 프롬프트·템플릿을 백업해야 합니다.

2단계 — 자동으로 할까요, 수동으로 할까요?

판단 기준은 아주 간단합니다. 전달받은 압축을 푼 폴더 안을 보세요.

폴더 안에 DRM_AI_설치및업데이트.bat 파일이 있다 자동 A장(자동 방법)으로 가세요. 이 방법을 권장합니다. 더블클릭 한 번이면 아래 수동 작업이 전부 자동으로 처리됩니다.
폴더 안에 그 파일이 없다 수동 B장(수동 방법)으로 가세요. 자동 설치 프로그램이 들어 있지 않은 배포본입니다.
자동 파일이 있어도 수동으로 할 수 있나요? 네, 가능합니다. 학교에서 관리하는 PC의 보안 정책 때문에 자동 프로그램이 막히는 경우, 또는 특정 단계만 다시 하고 싶은 경우에는 B장을 따라 하세요. 두 방법의 결과는 완전히 같습니다.

두 방법은 무엇이 다른가요?

비교 항목 자동 A장 수동 B장
사용자가 하는 일 더블클릭 1번 + 번호/Y·N 입력 몇 번 7단계를 순서대로 직접 수행

중간에 멈췄을 때 다시 더블클릭하면 안 된 부분만 이어서 진행 어느 단계까지 했는지 직접 기억해야 함

2. 공통 준비 (자동 · 수동 모두 해당)

2-1) 압축 풀기

  1. 전달받은 DRM_AI_학교명_v0.0.zip 파일을 바탕화면에 둡니다.
  2. ZIP 파일에 마우스 오른쪽 클릭 → [압축 풀기...] (또는 [모두 압축 풀기])를 누릅니다.
  3. 같은 이름의 일반 폴더가 생깁니다. 이 폴더를 엽니다.
가장 흔한 실수: 압축을 풀지 않고 ZIP 파일을 더블클릭해 그 안에서 바로 실행하는 경우입니다. 반드시 압축을 푼 폴더에서 작업하세요.

폴더 안에는 대략 이런 파일들이 있습니다 — DRM_AI_학교명_v0.0.xlam(엑셀 추가 기능), 여러 개의 .py 파일, 배포본에 따라 DRM_AI_설치및업데이트.bat(자동 설치 프로그램)과 python-3.13.9-amd64.exe(파이썬 설치 파일).

2-2) 올인원 도우미 설치 (처음 설치하는 분만)

  1. 제공된 All-in-One_Assistant_for_teacher_v0.0_setup.exe 로 올인원 도우미를 설치합니다.
  2. 설치가 끝나면 올인원을 한 번 실행해, 40번 「서식 생성, DRM AI설치」 화면이 정상적으로 열리는지만 확인하고 닫습니다.

이미 올인원을 쓰고 있다면 이 단계는 건너뛰어도 됩니다.

지금은 여기까지만 하세요 — 40번 화면의 [설명서 보기]는 아직 따라 하지 않습니다.

40번 화면 하단의 [설명서 보기] 버튼을 누르면 안내문이 열리는데, 그 안에는 DRM AI 설치가 끝나야만 할 수 있는 작업이 섞여 있습니다. 특히 부록3(빠른 실행 도구 모음 추가) 은 엑셀 상단에 [DRM AI 실행] 버튼이 이미 나타나 있어야 진행할 수 있어서, 설치 전에 시도하면 그 버튼을 찾지 못해 막힙니다.

따라서 이 설명서는 순서를 이렇게 잡았습니다.

2장 준비  →  A장 또는 B장 으로 DRM AI 설치  →  C장 설치 후 마무리 설정

[설명서 보기] 내용을 실제로 따라 하는 것은 C-4 단계입니다. 지금은 넘어가세요.

2-3) 프로그램 모두 종료

엑셀, 워드, 올인원 도우미를 모두 종료합니다. 화면에 창이 안 보여도 백그라운드에 남아 있을 수 있으니, 몇 초 기다린 뒤 진행하세요.

2-4) 개인 프롬프트 · 템플릿 백업 (업데이트하는 분만 · 매우 중요)

백업은 반드시 업데이트 "전"에 해야 합니다.

개인 프롬프트와 템플릿의 백업은 엑셀을 실행한 뒤, DRM AI 메뉴 안에서 그 기능을 사용하는 각 메뉴마다 직접(수동으로) 하는 방법뿐입니다.

  • 설치·업데이트 프로그램이 대신 백업해 주지 않습니다.
  • 올인원 도우미를 비롯한 다른 프로그램으로도 할 수 없습니다.
  • 백업한 파일은 바탕화면 등 안전한 위치에 따로 보관하세요.

백업을 마쳤으면 엑셀을 완전히 종료한 뒤 설치를 진행합니다. 업데이트가 끝난 뒤에는 같은 방식으로 DRM AI 메뉴에서 각 기능별로 직접 복원합니다.

기존 추가 기능 파일(.xlam) 자체는 자동 방법을 쓰면 프로그램이 알아서 백업해 둡니다. 직접 챙겨야 하는 것은 개인 프롬프트와 템플릿뿐입니다.
참고: DRM AI 사용을 위해 Acrobat Reader를 따로 설치할 필요가 없습니다. PDF 관련 기능은 DRM AI 내부 처리 방식으로 동작합니다.

자동 A. 자동 방법 — 더블클릭 한 번

이 프로그램 하나가 예전에 손으로 하던 일 — 매크로 차단 해제, 신뢰 위치 등록, Python 설치, 필수 패키지 설치, 엑셀 추가 기능 등록 — 을 전부 자동으로 처리합니다. 관리자 권한(비밀번호)은 필요 없습니다.

여러 번 다시 실행해도 안전합니다. 중간에 창이 닫히거나 오류가 나면 그냥 다시 더블클릭하세요. 이미 끝난 단계는 건너뛰고 안 된 부분만 이어서 진행합니다.

A-1. 실행하기

  1. 압축을 푼 폴더에서 DRM_AI_설치및업데이트.bat 를 더블클릭합니다.

    확장명 표시가 꺼져 있으면 DRM_AI_설치및업데이트 로만 보입니다.

  2. 파란색 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누릅니다.

    인터넷에서 받은 새 프로그램에 늘 나오는 확인 창일 뿐입니다.

  3. 검은 창이 열리며 설치가 시작됩니다. 이제 화면의 질문에만 답하면 됩니다.
압축 파일을 엑셀 추가 기능 폴더에 풀어서 실행하면 프로그램이 일부러 멈춥니다. 그 폴더에는 다른 프로그램의 추가 기능도 있어 위험하기 때문입니다. 바탕화면 같은 일반 폴더에 다시 풀고 실행하세요.

A-2. 화면 질문에 답하기

키보드로 번호나 글자를 입력한 뒤 Enter 를 누르면 됩니다.

① 처음 설치인지, 업데이트인지 선택

[1] 처음 설치 - 이 PC 에서 DRM AI 를 처음 사용합니다. [2] 업데이트 - 이미 사용 중이며 새 버전으로 교체합니다. [3] 종료 번호를 입력하고 Enter 를 누르세요 (1/2/3): _

② 인터넷 연결 확인 (자동)

연결되어 있으면 아무것도 묻지 않고 넘어갑니다. 연결이 안 되어 있으면 [1] 다시 확인 / [2] 일단 계속 / [3] 종료를 묻습니다. 가능하면 Wi-Fi나 랜선을 연결한 뒤 1 을 권장합니다.

③ (업데이트만) 백업했는지 확인

------ 업데이트 전 반드시 확인하세요 -------------------------- | 엑셀의 DRM AI 메뉴를 통해 필요한 프롬프트와 템플릿을 | | 백업했습니까? | | (자동으로 백업되지 않으며, 다른 프로그램으로도 못 합니다) | -------------------------------------------------------------- 백업을 완료했거나 백업이 필요 없으면 Y, 중단하고 백업하러 가려면 N (Y/N): _
  • 백업했거나 원래 개인 프롬프트·템플릿을 쓰지 않는다면 → Y
  • 아직 안 했다면 → N. 프로그램이 안전하게 멈춥니다. 2-4대로 백업한 뒤 bat를 다시 더블클릭하세요.

④ 엑셀 · 워드 · 올인원 닫기

실행 중인 프로그램이 있으면 알려 줍니다. 모두 닫고 Enter 만 누르면 이어집니다.

⑤ 자동 처리 구간 (지켜보기만)

기존 버전 백업 → 새 추가 기능 복사와 매크로 차단 해제 → 신뢰 위치 등록 → Python 파일 배치가 자동으로 진행됩니다.

⑥ Python이 없는 PC라면 자동 설치 제안

[주의] PC 에서 Python 을 찾지 못했습니다. DRM AI 의 AI 기능에는 Python 이 필요합니다. 동봉된 설치 파일로 Python 을 설치합니다: python-3.13.9-amd64.exe (현재 사용자 전용 설치, PATH 자동 등록 - 관리자 권한 불필요) 지금 자동으로 설치할까요? (Enter=설치 / S=이 단계 건너뛰기): _

그냥 Enter 를 누르세요. 설치 진행 창이 뜨면 아무것도 누르지 말고 끝날 때까지 기다립니다. (인터넷 불필요)

⑦ 필수 패키지 설치 (가장 오래 걸림)

영문 글자가 빠르게 올라가며 5~20분 걸립니다. 정상입니다. 창을 닫지 말고 기다리면 엑셀 추가 기능 등록과 최종 점검까지 자동으로 끝납니다.

B-5. 매크로 차단 해제 (놓치면 메뉴가 안 나옵니다)

수동 설치에서 가장 많이 빠뜨리는 단계입니다.

인터넷이나 메신저로 받은 .xlam 파일에는 Windows가 "다른 PC에서 받은 파일"이라는 차단 표시를 붙입니다. 이 표시를 지우지 않으면 엑셀이 매크로를 막아 DRM AI 메뉴가 아예 나타나지 않습니다.

  3. [적용] → [확인] 을 누릅니다.

그 문구가 보이지 않으면 이미 차단이 없는 상태이므로 그대로 넘어가면 됩니다. 폴더 안의 .py 파일에도 같은 표시가 있을 수 있으니, 나중에 기능 오류가 나면 동일하게 해제해 보세요.

A장(자동) 또는 B장(수동)을 모두 마친 다음에 진행하세요. 아래 작업들은 엑셀에 DRM AI 메뉴가 이미 나타나 있어야 할 수 있습니다. 설치 전에 시도하면 화면에서 버튼을 찾지 못해 진행되지 않습니다.

엑셀에 DRM AI 메뉴가 안 보임 ① 엑셀을 완전히 종료했다가 다시 실행 → ② B-5 매크로 차단 해제를 했는지 확인 → ③ B-6 방법 ㉯로 직접 등록. 수동 설치에서 가장 흔한 원인은 차단 해제 누락입니다.
설치·덮어쓰기 중 파일 오류 엑셀·워드·올인원을 모두 종료한 뒤 다시 시도하세요. 백신 검사 중이면 끝난 뒤 진행합니다.
python 명령이 인식되지 않음 Python을 다시 설치하며 Add python.exe to PATH 를 체크하세요. CMD 창은 닫았다가 새로 열어야 반영됩니다.
모듈 없음 오류 (예: PySide6, PyMuPDF) B-3 패키지 설치 명령을 다시 실행하세요.
기능 실행 시 파일을 찾을 수 없다는 오류 .py 파일이 C:\MyTrustedFiles 에 있는지 확인하세요. 다른 폴더에 있으면 동작하지 않습니다.
Gemini 실행 오류 API 설정을 임의로 바꿨는지 확인하고, 바꿨다면 학교 관리자에게 기본값 복구를 요청하세요.

6-2) 자동 검은 창에 이런 문구가 나오면

화면 문구이렇게 하세요
"Install-DRMAI.ps1 파일을 찾을 수 없습니다" ZIP 압축을 풀지 않고 실행한 경우입니다. 2-1대로 압축을 풀고, 풀린 폴더에서 다시 더블클릭하세요.
"Excel 이(가) 실행 중입니다" / "Word..." / "올인원..." 해당 프로그램을 모두 닫고 Enter. 창이 안 보여도 남아 있을 수 있으니 몇 초 기다렸다 다시 Enter.
"인터넷에 연결되어 있지 않거나..." Wi-Fi/랜선을 연결하고 1. 지금 어렵다면 2(일단 계속) 후, 나중에 인터넷이 되는 곳에서 bat를 다시 실행하면 남은 단계가 완료됩니다.
"COM 자동 등록 실패" + 수동 절차 안내 화면에 나온 대로 B-6 방법 ㉯를 따라 하면 1분 안에 끝납니다. 나머지는 이미 완료된 상태입니다.
"작업이 일부 항목 실패와 함께 끝났습니다" (코드 2) 대부분 인터넷 문제입니다. 연결을 확인하고 다시 더블클릭하세요. 안 된 부분만 다시 진행됩니다.
"작업이 코드 1 로 끝났습니다" 화면 위쪽의 [실패] 줄을 먼저 확인하세요. "이 시스템에서 스크립트를 실행할 수 없으므로" 같은 문구가 보이면 학교 관리 PC의 보안 정책이 막은 것입니다. 이때는 B장 수동 방법으로 진행하거나 학교 관리자에게 화면을 캡처해 문의하세요.
"사용자 요청으로 작업을 중단했습니다" (코드 3) 오류가 아니라 정상 종료입니다. 변경된 내용이 없으므로 준비되면 다시 실행하세요.
"이 프로그램을 Excel 추가기능 폴더 안에서 실행할 수 없습니다" 압축을 추가 기능 폴더에 풀어 실행한 경우입니다. 바탕화면 등 일반 폴더에 다시 풀고 실행하세요.
"추가기능(.xlam) 파일이 N개 발견되었습니다" 목록에서 이번에 받은 파일의 번호를 입력하세요. 모르겠으면 그냥 Enter(가장 최신 파일).
"기존 파일을 백업하지 못한 상태로 덮어쓸 수 없습니다" 엑셀·백신 검사를 완전히 종료한 뒤 다시 실행하세요. 파일을 지키기 위해 일부러 멈춘 것입니다.

7. 자주 묻는 질문

Q1. 설명서의 버전 숫자와 내가 받은 파일의 숫자가 달라요.

정상입니다. 이 설명서는 모든 버전에 공통으로 적용되도록 만들어졌습니다. 숫자는 신경 쓰지 말고 내가 받은 파일을 그대로 사용하세요.

Q2. 자동과 수동 중 무엇이 더 좋은가요?

폴더에 DRM_AI_설치및업데이트.bat 가 있다면 자동을 권장합니다. 빠뜨리기 쉬운 매크로 차단 해제까지 자동으로 처리하기 때문입니다. 결과물은 두 방법이 완전히 같습니다.

Q3. 실수로 중간에 창을 닫았어요.

자동 다시 더블클릭하면 됩니다. 몇 번을 실행해도 안전합니다.
수동 어느 단계까지 했는지 확인하고 그 단계부터 다시 하세요. B-3 패키지 설치와 B-4 파일 복사는 여러 번 반복해도 안전합니다.

Q4. 관리자 비밀번호를 물어보나요?

아니요. 관리자 권한 없이 동작하도록 만들어져 있어 비밀번호 창(UAC)이 뜨지 않는 것이 정상입니다.

Q5. 인터넷이 안 되는 곳에서도 설치할 수 있나요?

추가 기능 등록과 Python 설치까지는 인터넷 없이 됩니다. 패키지 설치 단계만 인터넷이 필요하므로, 나중에 인터넷이 되는 곳에서 해당 단계만 다시 실행해 마무리하면 됩니다.

Q6. 예전 버전은 어디로 가나요?

자동 지워지지 않고 자동으로 백업됩니다. 완료 화면에 백업 폴더 위치가 표시됩니다.
수동 덮어쓰기 전에 기존 .xlam 파일을 다른 폴더에 직접 복사해 두는 것을 권장합니다.

Q7. 다른 엑셀 추가 기능을 쓰고 있는데 영향이 없나요?

없습니다. 설치·제거 프로그램은 이름이 DRM_AI 로 시작하는 파일만 다룹니다. 수동으로 작업할 때도 그 외의 파일은 건드리지 마세요.

Q8. 개인 프롬프트·템플릿을 백업하지 않고 업데이트했어요.

먼저 학교 관리자(배포자)에게 문의하세요. 이후에는 업데이트 전에 반드시 2-4의 백업을 먼저 수행하시기 바랍니다.
