1. 시작하기 전 확인 (2가지)

두 가지만 확인하면 바로 설치를 시작할 수 있습니다.

1-1) 처음 설치인가요, 업데이트인가요?

처음 설치 이 PC에서 DRM AI를 처음 사용합니다. Python 설치부터 모두 필요합니다.
업데이트 이미 사용 중이고 새 버전으로 교체합니다. 먼저 개인 프롬프트·템플릿을 백업해야 합니다.

1-2) 폴더 안에 설치 프로그램이 있는지 확인

전달받은 압축을 푼 폴더 안을 보세요. 이 파일 하나만 찾으면 됩니다.

폴더 안에 DRM_AI_설치및업데이트.bat 파일이 있다 정상 바로 3장으로 가세요. 더블클릭 한 번이면 됩니다.
폴더 안에 그 파일이 없다 먼저 2-1) 대로 압축을 제대로 풀었는지 확인하세요. (ZIP 파일 안에서 바로 실행하면 파일이 안 보일 수 있습니다) 그래도 없다면 학교 관리자(배포자)에게 "설치 프로그램이 포함된 배포본"을 요청하세요. 파일을 임의로 옮기거나 직접 설치하지 마세요.

설치 프로그램이 대신 해 주는 일

아래 다섯 가지는 모두 자동으로 처리됩니다. 설치 자체를 위해 직접 하실 일은 마지막 한 가지뿐이며, 그 밖에 4장 에서 한 번만 하면 되는 마무리 설정 2가지(빠른 실행 등록 · 안내문 확인)가 있습니다.

자동 프로그램이 하는 일 직접 하실 일
① 매크로 차단 해제
② Excel 신뢰 위치 등록
③ Python 설치
④ 필수 패키지 설치
⑤ 추가 기능 파일 복사 		처음 설치라면 엑셀에서 [찾아보기]로 .xlam 을 한 번 직접 등록 (4-1 에서 안내합니다)
업데이트하시는 분은 이것도 하지 않으셔도 됩니다.

설치에 걸리는 시간은 약 10~30분이며 대부분은 기다리는 시간입니다. 중간에 멈추더라도 다시 더블클릭하면 안 된 부분만 이어서 진행됩니다. 설치가 끝나면 추가 기능은 %AppData%\Microsoft\AddIns 에, Python 파일은 C:\MyTrustedFiles 에 놓입니다.

2. 설치 준비

2-1) 압축 풀기

  1. 전달받은 DRM_AI_학교명_v0.0.zip 파일을 찾습니다. 위치는 어디든 상관없습니다 — 내려받은 그대로 다운로드 폴더에 두셔도 되고, 찾기 편한 곳(바탕화면, 문서 폴더 등)으로 옮기셔도 됩니다.
  2. ZIP 파일에 마우스 오른쪽 클릭 → [압축 풀기...] (또는 [모두 압축 풀기])를 누릅니다.
  3. 같은 이름의 일반 폴더가 생깁니다. 이 폴더를 엽니다.
가장 흔한 실수: 압축을 풀지 않고 ZIP 파일을 더블클릭해 그 안에서 바로 실행하는 경우입니다. 반드시 압축을 푼 폴더에서 작업하세요.

폴더 위치에 제한은 없습니다. 다만 엑셀 추가 기능 폴더(%AppData%\Microsoft\AddIns) 안에는 풀지 마세요 — 다른 프로그램의 추가 기능이 함께 있는 곳이라 설치 프로그램이 일부러 멈춥니다. C:\Program Files 처럼 관리자 권한이 필요한 폴더도 피하시면 됩니다.

폴더 안에는 대략 이런 파일들이 있습니다 — DRM_AI_학교명_v0.0.xlam(엑셀 추가 기능), 여러 개의 .py 파일, 배포본에 따라 DRM_AI_설치및업데이트.bat(자동 설치 프로그램)과 python-3.13.9-amd64.exe(파이썬 설치 파일).

2-2) 올인원 도우미 설치 (처음 설치하는 분만)

  1. 제공된 All-in-One_Assistant_for_teacher_v0.0_setup.exe 로 올인원 도우미를 설치합니다.
  2. 설치가 끝나면 올인원을 한 번 실행해, 40번 「서식 생성, DRM AI설치」 화면이 정상적으로 열리는지만 확인하고 닫습니다.

이미 올인원을 쓰고 있다면 이 단계는 건너뛰어도 됩니다.

지금은 여기까지만 하세요 — 40번 화면의 [설명서 보기]는 아직 따라 하지 않습니다.

40번 화면 하단의 [설명서 보기] 버튼을 누르면 안내문이 열리는데, 그 안에는 DRM AI 설치가 끝나야만 할 수 있는 작업이 섞여 있습니다. 특히 부록3(빠른 실행 도구 모음 추가) 은 엑셀 상단에 [DRM AI 실행] 버튼이 이미 나타나 있어야 진행할 수 있어서, 설치 전에 시도하면 그 버튼을 찾지 못해 막힙니다.

따라서 이 설명서는 순서를 이렇게 잡았습니다.

2-3) 프로그램 모두 종료

엑셀, 워드, 올인원 도우미를 모두 종료합니다. 화면에 창이 안 보여도 백그라운드에 남아 있을 수 있으니, 몇 초 기다린 뒤 진행하세요.

2-4) 개인 프롬프트 · 템플릿 백업 (업데이트하는 분만 · 매우 중요)

백업은 반드시 업데이트 "전"에 해야 합니다.

개인 프롬프트와 템플릿의 백업은 엑셀을 실행한 뒤, DRM AI 메뉴 안에서 그 기능을 사용하는 각 메뉴마다 직접 하는 방법뿐입니다.

  • 설치·업데이트 프로그램이 대신 백업해 주지 않습니다.
  • 올인원 도우미를 비롯한 다른 프로그램으로도 할 수 없습니다.
  • 백업한 파일은 바탕화면 등 안전한 위치에 따로 보관하세요.

백업을 마쳤으면 엑셀을 완전히 종료한 뒤 설치를 진행합니다. 업데이트가 끝난 뒤에는 같은 방식으로 DRM AI 메뉴에서 각 기능별로 직접 복원합니다.

기존 추가 기능 파일(.xlam) 자체는 자동 방법을 쓰면 프로그램이 알아서 백업해 둡니다. 직접 챙겨야 하는 것은 개인 프롬프트와 템플릿뿐입니다.
참고: DRM AI 사용을 위해 Acrobat Reader를 따로 설치할 필요가 없습니다. PDF 관련 기능은 DRM AI 내부 처리 방식으로 동작합니다.

3. 설치하기 — 더블클릭 한 번

이 프로그램 하나가 예전에 손으로 하던 일 — 매크로 차단 해제, 신뢰 위치 등록, Python 설치, 필수 패키지 설치, 추가 기능 파일 복사 — 을 자동으로 처리합니다. 관리자 권한(비밀번호)은 필요 없습니다.

설치를 위해 자동이 하지 않는 일은 딱 하나입니다. 처음 설치라면 마지막에 엑셀에서 .xlam 을 [찾아보기]로 직접 한 번 등록해야 합니다 (절차는 4-1 에 그대로 적어 두었습니다). 업데이트에는 해당하지 않습니다.

여러 번 다시 실행해도 안전합니다. 중간에 창이 닫히거나 오류가 나면 그냥 다시 더블클릭하세요. 이미 끝난 단계는 건너뛰고 안 된 부분만 이어서 진행합니다.

3-1. 실행하기

  1. 압축을 푼 폴더에서 DRM_AI_설치및업데이트.bat 를 더블클릭합니다.

    확장명 표시가 꺼져 있으면 DRM_AI_설치및업데이트 로만 보입니다.

  2. 파란색 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누릅니다.

    인터넷에서 받은 새 프로그램에 늘 나오는 확인 창일 뿐입니다.

  3. 검은 창이 열리며 설치가 시작됩니다. 이제 화면의 질문에만 답하면 됩니다.
압축 파일을 엑셀 추가 기능 폴더에 풀어서 실행하면 프로그램이 일부러 멈춥니다. 그 폴더에는 다른 프로그램의 추가 기능도 있어 위험하기 때문입니다. 다운로드·바탕화면·문서 등 평소에 쓰는 일반 폴더에 다시 풀고 실행하세요. (어느 폴더든 괜찮습니다)

3-2. 화면 질문에 답하기

키보드로 번호나 글자를 입력한 뒤 Enter 를 누르면 됩니다.

① 처음 설치인지, 업데이트인지 선택

[1] 처음 설치 - 이 PC 에서 DRM AI 를 처음 사용합니다. [2] 업데이트 - 이미 사용 중이며 새 버전으로 교체합니다. [3] 종료 번호를 입력하고 Enter 를 누르세요 (1/2/3): _

② 인터넷 연결 확인 (자동)

연결되어 있으면 아무것도 묻지 않고 넘어갑니다. 연결이 안 되어 있으면 [1] 다시 확인 / [2] 일단 계속 / [3] 종료를 묻습니다. 가능하면 Wi-Fi나 랜선을 연결한 뒤 1 을 권장합니다.

③ (업데이트만) 백업했는지 확인

------ 업데이트 전 반드시 확인하세요 -------------------------- | 엑셀의 DRM AI 메뉴를 통해 필요한 프롬프트와 템플릿을 | | 백업했습니까? | | (자동으로 백업되지 않으며, 다른 프로그램으로도 못 합니다) | -------------------------------------------------------------- 백업을 완료했거나 백업이 필요 없으면 Y, 중단하고 백업하러 가려면 N (Y/N): _

  • 아직 안 했다면 → N. 프로그램이 안전하게 멈춥니다. 2-4대로 백업한 뒤 bat를 다시 더블클릭하세요.

④ 엑셀 · 워드 · 올인원 닫기

실행 중인 프로그램이 있으면 알려 줍니다. 모두 닫고 Enter 만 누르면 이어집니다.

⑤ 자동 처리 구간 (지켜보기만)

기존 버전 백업 → 새 추가 기능 복사와 매크로 차단 해제 → 신뢰 위치 등록 → Python 파일 배치가 자동으로 진행됩니다.

⑥ Python이 없는 PC라면 자동 설치 제안

[주의] PC 에서 Python 을 찾지 못했습니다. DRM AI 의 AI 기능에는 Python 이 필요합니다. 동봉된 설치 파일로 Python 을 설치합니다: python-3.13.9-amd64.exe (현재 사용자 전용 설치, PATH 자동 등록 - 관리자 권한 불필요) 지금 자동으로 설치할까요? (Enter=설치 / S=이 단계 건너뛰기): _

"작업이 코드 1 로 끝났습니다" 화면 위쪽의 [실패] 줄을 먼저 확인하세요. "이 시스템에서 스크립트를 실행할 수 없으므로" 같은 문구가 보이면 학교 관리 PC의 보안 정책이 막은 것입니다. 학교 관리자(배포자)에게 화면을 캡처해 문의하세요. 급할 때는 아래 6-3 의 절차로 직접 마무리할 수 있습니다.
"사용자 요청으로 작업을 중단했습니다" (코드 3) 오류가 아니라 정상 종료입니다. 변경된 내용이 없으므로 준비되면 다시 실행하세요.
"이 프로그램을 Excel 추가기능 폴더 안에서 실행할 수 없습니다" 압축을 추가 기능 폴더에 풀어 실행한 경우입니다. 다운로드·바탕화면·문서 등 평소에 쓰는 일반 폴더에 다시 풀고 실행하세요. (어느 폴더든 괜찮습니다)
"추가기능(.xlam) 파일이 N개 발견되었습니다" 목록에서 이번에 받은 파일의 번호를 입력하세요. 모르겠으면 그냥 Enter(가장 최신 파일).
"이 Python 에는 pip 이 없고 자동 복구(ensurepip)도 되지 않았습니다." 인터넷 문제가 아닙니다. 다시 더블클릭해도 해결되지 않습니다. 배포 폴더의 python-3.13.x-amd64.exe 로 Python 을 다시 설치하되, 설치 첫 화면의 Add python.exe to PATH 를 반드시 체크하세요. 그 뒤 bat 를 다시 더블클릭하면 이어서 진행됩니다.
"다음 패키지를 설치하지 못했습니다: ..." 또는
"다음 패키지를 불러오지 못했습니다: ..."		 인터넷 연결을 확인하고 다시 더블클릭하세요(이미 설치된 것은 건너뜁니다). 두세 번 해도 같은 이름이 남으면, 6-3 ② 의 CMD 창에서 화면에 적힌 그 이름만 설치하세요 — 예: python -m pip install PySide6
"설치된 패키지 사이에 버전이 맞지 않는 부분이 있습니다:" 실패가 아닙니다. 대개 그대로 동작하므로 그냥 진행하세요. 나중에 기능 오류가 나면 bat 를 한 번 더 실행하면 정리됩니다.
"기존 파일을 백업하지 못한 상태로 덮어쓸 수 없습니다" 엑셀·백신 검사를 완전히 종료한 뒤 다시 실행하세요. 파일을 지키기 위해 일부러 멈춘 것입니다.

6-3) 직접 해결하기 (설치 프로그램이 끝내지 못했을 때만)

보통은 여기까지 오실 일이 없습니다. DRM_AI_설치및업데이트.bat 를 다시 더블클릭하면 안 된 부분만 이어서 처리합니다. 두세 번 다시 실행해도 같은 문제가 남을 때만 아래 항목 중 해당하는 것 하나만 따라 하세요.

① 메뉴가 안 보일 때 — .xlam 차단 해제

인터넷이나 메신저로 받은 파일에는 Windows 가 "다른 PC에서 받은 파일"이라는 차단 표시를 붙입니다. 이 표시가 남아 있으면 엑셀이 매크로를 막아 DRM AI 메뉴가 아예 나타나지 않습니다.

  1. 압축을 푼 폴더에서 DRM_AI_학교명_v0.0.xlam 파일에 마우스 오른쪽 클릭 → [속성] 을 누릅니다.
  2. 창 맨 아래에 보안: 이 파일은 다른 컴퓨터에서 왔으며 ... 문구와 [차단 해제] 체크 상자가 있으면 체크합니다.
  3. [적용] → [확인] 을 누른 뒤, 4-1 의 [찾아보기] 등록을 다시 하세요.

그 문구가 보이지 않으면 이미 차단이 없는 상태이므로 넘어가면 됩니다. C:\MyTrustedFiles 폴더의 .py 파일에도 같은 표시가 있을 수 있으니, 나중에 기능 오류가 나면 같은 방법으로 해제해 보세요.

② "모듈 없음" 오류가 날 때 — 패키지 다시 설치

CMD 창 여는 법: 키보드 Win 키를 누르고 cmd 를 입력한 뒤 Enter 를 누르면 검은 창이 열립니다. 아래 세 줄을 한 번에 복사해 붙여넣고 Enter 를 누르세요. (붙여넣기는 마우스 오른쪽 클릭)

먼저 python --version 을 입력해 Python 3.13.x 처럼 버전이 나오는지 확인하세요. 명령을 알 수 없다는 메시지가 나오면 아래 명령이 모두 실패하므로, 이 문단 맨 아래의 Add python.exe to PATH 안내를 먼저 처리하세요.

python -m pip install --upgrade --disable-pip-version-check --retries 5 --timeout 60 pip
python -m pip install --disable-pip-version-check --retries 5 --timeout 60 requests openai google-genai pillow PyMuPDF yt-dlp PySide6 openpyxl
python -m pip install --upgrade --disable-pip-version-check --retries 5 --timeout 60 google-auth google-auth-oauthlib google-api-python-client
제대로 됐는지 확인하는 명령 — 아래 한 줄을 붙여넣고 Enter 를 누르세요. 
python -c "import requests, openai, PIL, fitz, yt_dlp, PySide6, openpyxl; from google import genai; print('IMPORT_OK')"

IMPORT_OK 가 보이면 성공입니다. 노란색 WARNING 은 무시해도 됩니다. ModuleNotFoundError: No module named 'xxx' 가 나오면 그 이름의 패키지만 다시 설치하세요 (예: python -m pip install PySide6).

python 명령이 인식되지 않으면 Python 을 다시 설치하며 Add python.exe to PATH 를 체크하세요. (설치 파일은 배포 폴더의 python-3.13.x-amd64.exe, 없으면 python.org 에서 64비트 3.13 이상) 권한 오류가 나면 첫 줄만 python -m pip install --user --upgrade pip 로 바꿔 실행하세요.

③ "파일을 찾을 수 없다"는 오류가 날 때 — Python 파일 확인

배포 폴더의 .py 파일 12개가 C:\MyTrustedFiles 에 모두 있어야 합니다. 없으면 그 폴더로 복사(덮어쓰기)하세요. (C:\MyTrustedFiles 폴더 자체가 없으면 C:\ 에 MyTrustedFiles 라는 이름으로 새 폴더를 만든 뒤 복사하세요)

api_handler.pygemini_parallel_processor.py
gpt_parallel_processor.pygemini_tts_parallel.py
video_tts_processor.pygemini_image_generate.py
imagen_image_generate.pyopenai_image_generate.py

.xlam 파일은 이 폴더에 넣지 않습니다. 다른 폴더에 두면 기능이 동작하지 않습니다.

④ 보안 정책으로 설치 프로그램이 막혔을 때 — 올인원 40번으로 추가 기능만 설치

이 방법은 DRM_AI_설치및업데이트.bat 이 폴더에 있는데 실행이 정책으로 막힐 때만 쓰는 임시 수단입니다.

폴더에 bat 파일이 아예 없다면 이 방법을 쓰지 말고 1-2) 대로 학교 관리자(배포자)에게 올바른 배포본을 요청하세요. 이 방법만으로는 Python 파일 배치와 차단 해제가 끝나지 않아 기능이 반쯤만 동작합니다.

  1. 엑셀을 모두 종료한 상태에서 올인원 도우미를 실행합니다.
  2. 40번 「서식 생성, DRM AI설치」 를 엽니다.
  3. .xlam 파일을 선택한 뒤 [추가 기능 복사하기] 를 실행합니다.
  4. 이어서 위 ②·③ 으로 Python 패키지와 파일을 갖추고, 4-1 의 [찾아보기] 등록까지 하면 설치가 완료됩니다.

이 방법으로도 해결되지 않으면 학교 관리자(배포자)에게 화면을 캡처해 문의하세요.

7. 자주 묻는 질문

Q1. 설명서의 버전 숫자와 내가 받은 파일의 숫자가 달라요.

정상입니다. 이 설명서는 모든 버전에 공통으로 적용되도록 만들어졌습니다. 숫자는 신경 쓰지 말고 내가 받은 파일을 그대로 사용하세요.

Q2. 직접 하나씩 설치하는 방법은 없나요?

설치 프로그램이 모든 단계를 대신 처리하므로 따로 하실 필요가 없습니다. 빠뜨리기 쉬운 매크로 차단 해제까지 자동으로 처리합니다. 설치가 도중에 막혔을 때만 6장 의 6-3) 직접 해결하기 를 쓰세요.

Q3. 실수로 중간에 창을 닫았어요.

다시 더블클릭하면 됩니다. 몇 번을 실행해도 안전하며, 안 된 부분만 이어서 진행됩니다.

Q4. 관리자 비밀번호를 물어보나요?

아니요. 관리자 권한 없이 동작하도록 만들어져 있어 비밀번호 창(UAC)이 뜨지 않는 것이 정상입니다.

Q5. 인터넷이 안 되는 곳에서도 설치할 수 있나요?

추가 기능 파일 복사와 Python 설치까지는 인터넷 없이 됩니다. 패키지 설치 단계만 인터넷이 필요하므로, 나중에 인터넷이 되는 곳에서 해당 단계만 다시 실행해 마무리하면 됩니다.

Q6. 예전 버전은 어디로 가나요?

지워지지 않고 자동으로 백업됩니다. 완료 화면에 백업 폴더 위치가 표시됩니다.

Q7. 다른 엑셀 추가 기능을 쓰고 있는데 영향이 없나요?

없습니다. 설치·제거 프로그램은 이름이 DRM_AI 로 시작하는 파일만 다룹니다. 추가 기능 폴더를 직접 열어 볼 때도 그 외의 파일은 건드리지 마세요.

Q8. 개인 프롬프트·템플릿을 백업하지 않고 업데이트했어요.

먼저 학교 관리자(배포자)에게 문의하세요. 이후에는 업데이트 전에 반드시 2-4의 백업을 먼저 수행하시기 바랍니다.
