엑셀과 올인원 교사 도우미로
시작하는 교원 업무 혁신

인공지능(AI) 기술과 강력한 데이터 엔진인 엑셀이 만났습니다. 단순 반복적인 교원 업무에 쏟는 몇 시간을 클릭 몇 번, 단 몇 초의 혁신으로 전환하는 비결을 엑셀 초보자의 눈높이에서 알기 쉽게 제시해 드립니다.

DRM AI와 올인원 교사 도우미를 함께 쓰면 무엇이 달라질까요?

DRM AI와 올인원 교사 도우미는 엑셀을 단순한 계산표가 아니라 교원 업무를 빠르고 안전하게 처리하는 작업대로 바꿔 줍니다. 어려운 코딩을 몰라도 예산, 문서, 학생 자료, AI 결과를 한곳에서 정리하고 필요한 기능으로 바로 연결할 수 있어 초보자도 쉽게 시작할 수 있습니다.

  • 원 단위 예산도 쉽게 처리합니다 API로 예산 데이터를 연결하면 원 단위 금액까지 정확하게 계산하고, 불필요한 여러 유료 계정 결제 없이 한 계정에서 API를 관리해 복잡한 결제 흐름을 단순화할 수 있습니다.
  • 확장성이 높습니다 학교 양식, 과목, 업무 방식에 맞게 엑셀, 한글, PDF, AI 기능을 자유롭게 연결해 활용할 수 있습니다.
  • 교사의 전문성이 커집니다 반복 작업 시간을 줄이고 수업 설계, 평가 문항 개발, 학생 관찰 기록처럼 교사의 판단이 중요한 일에 더 집중할 수 있습니다.
  • 개인 정보 걱정을 줄입니다 학교 문서를 무작정 외부 서비스에 복사해 넣는 방식보다, 필요한 데이터만 정리해 통제된 절차로 처리할 수 있습니다.

1. AI 시대, 교사가 엑셀을 사용할 때 얻는 강력한 유익

인공지능과 엑셀의 결합은 교사 생산성을 무한대로 늘려줍니다.

🤖

AI는 '정리된 표'를 가장 좋아합니다

생성형 AI(GPT, Gemini)에 줄글로 질문을 던지는 것은 효율이 낮습니다. 엑셀의 행과 열 구조로 정돈된 데이터를 활용하면, AI는 완벽한 일관성과 형식에 맞춰 맞춤형 평가 기록이나 수업 문항을 생성할 수 있습니다.

⚡

수백 명의 처리를 한 번에 (병렬 처리)

웹에서 ChatGPT 창을 열고 학생 30명의 생활기록부 의견이나 오탈자를 하나씩 붙여넣어 수정하는 것은 여전히 노동입니다. DRM AI는 엑셀 셀 값을 한 번에 API로 보내 30명이든 300명이든 채팅 방식보다 대폭 절감된 시간 안에 동시에 처리 결과를 받아옵니다.

⏰

순수 교육과 지도 연구 시간 확보

수업 지도안의 문항 출제, 학생부 규정 위반 검사, PDF 분할 저장 등 불필요하게 시간을 잡아먹는 '기계적 반복 작업'을 자동화하여 업무 스트레스를 획기적으로 줄이고 학생들과 눈을 맞출 시간을 보장해 줍니다.

3. 행과 열, 프롬프트, 그리고 추가 프롬프트 병렬처리

엑셀과 AI 연동의 핵심 원리를 인터랙티브 시뮬레이션으로 쉽게 파악해 보세요.

핵심 개념 정의

  • 행(Row): 엑셀의 가로줄로, 개별 처리 단위인 1개의 문항 정보가 들어갑니다.
  • 열(Column): 엑셀의 세로줄로, 출제에 반영할 변수(내용영역, 발문/문항 유형, 정답 번호, 난이도 등)를 분할하여 지정합니다.
  • 프롬프트 (Prompt): AI가 지켜야 할 메인 지침서(역할, 2022 개정 교육과정 기준, 5지선다 포맷 등). [프롬프트_출제0617.txt]
  • 추가 프롬프트 (Extra Prompt): 각 행의 데이터를 헤더명과 수식으로 연결하여 한 편의 구체적인 요 청문서로 조합한 것입니다. [출제자료0618.xlsx]의 H열 구조를 참조합니다.
  • 병렬처리 (Parallel Processing): 수십 개의 행을 AI에게 동시에 전달하여 몇 시간 걸릴 출제 작업을 단 몇 분 만에 완료하는 기술입니다.

4. 올인원 교사 도우미를 통한 학생부(생활기록부) 점검 프로세스

개인정보 보호와 금지어 검출을 원클릭으로 완벽하게 제어합니다.

생활기록부 오류 검출을 위한 4가지 대응책

올인원 교사 도우미는 교육청 및 학교 정보보안/학생부 작성 지침에 부합하도록 문서를 점검합니다.

🔴 학생부 기재 금지 단어 적발: 교내대회, 대회 수상실적, 사교육 유발 단어(유튜브, 학원, 외부 단체명 등) 및 어학 시험 성적 등 나이스 필터 단어 검출.
🟠 문법 및 부적절 단어 오류: 1인칭 시점 단어("나의", "내가", "우리들"), 감정 및 주관적 묘사("깨달음", "느낌") 또는 2칸 이상의 무의미한 연속 공백 검출.
🔵 개인정보 및 출력정보 완벽 제거: 교사 간 교차 검토 및 점검 공유 과정에서 발생할 수 있는 보안 노출을 막기 위해, 워터마크, 출력자 인적사항, IP 정보 등을 PDF 레이어에서 원클릭으로 소거.
🟢 학생 개별 학생부 파일 종합 검사: DRM AI의 행단위 병렬 처리 기능과 특화된 점검 프롬프트를 활용하여 학생별 PDF 파일의 전 영역을 대상으로 기재 금지사항 및 누락 오류, 맥락 검사를 원클릭으로 일괄 자동 종합 분석.

학생부 오류 점검 절차

아래 순서대로 진행하면 학교 구성원이 같은 기준으로 학생부 오류를 찾고, 담당 교사가 원본 문서에 최종 반영할 수 있습니다. 핵심은 검토 파일 유형 정하기(doc, pdf) → 각 파일 유형에 맞는 기능 수행 → 필요시 추가 하이라이트 표시 → 하이라이트된 부분만 PDF로 추출 → 원본 수정 안내입니다.

Step 1

📁 검토 파일 유형 정하기(doc, pdf)

나이스에서 출력한 원본 생활기록부 자료의 파일 형식을 확인합니다. 개별 파일이나 소량 검토는 워드(.doc) 검사 흐름으로, 매우 많은 파일을 대량으로 검사하는 경우 PDF 검사 흐름으로 유형을 결정합니다.

1단계: 파일 분류
Step 2

🔍 각 파일 유형에 맞는 기능 수행

결정한 파일 유형에 맞게 자동 점검 기능을 가동합니다. 워드 파일은 '학생부 항목별 워드파일검사'를, PDF 파일은 'PDF 하이라이트 처리, 엑셀 저장'을 실행하여 기재 금지어를 1차 검출합니다.

2단계: 자동 검출
Step 3

✍️ 필요시 추가 하이라이트 표시

일괄 검출된 보고서 외에도, MS Word의 기본 맞춤법 검사 기능을 활용해 문맥이나 규정에 맞지 않는 표현을 2차 수동 강조 표시합니다.

3단계: 상세 검토
Step 4

📄 하이라이트된 부분만 PDF로 추출

정정 대조표 작성을 위해, 주석 및 하이라이트로 강조된 페이지만을 따로 수집하는 'PDF 주석 페이지 추출, 엑셀 저장' 기능을 실행하여 실제 정정이 필요한 오탈자 영역만 깔끔하게 추출합니다.

4단계: 정정 대상 추출
Step 5

📝 원본 수정 안내

최종적으로 정정 대상 부분만 모은 주석 추출본 PDF 파일과 엑셀 리포트 목록을 담당 교사에게 전달하여 나이스(NEIS) 시스템의 원본 생활기록부 내용을 고치도록 수정 안내를 진행합니다.

5단계: NEIS 원본 반영

🛠️ 작업 상황별 학생부 점검 최적 프로세스 가이드

학생들이나 교사가 작성 중인 여러 개의 개별 학생부 워드 파일에서 기재 금지어와 오류를 선제 적발하는 최적 프로세스입니다.

Step 1

📁 개별 워드 준비

검사할 학생들의 항목별 워드 파일(.doc)들을 단일 폴더에 한꺼번에 준비합니다. (※ 중요: 나이스에서 내려받은 원본 .doc 형식이어야 하며, 한글과컴퓨터 한워드에서 열고 저장한 파일로는 절대 작업할 수 없습니다.)

작업 대상 준비
Step 2

🔍 금지어 일괄 검사

올인원 도우미의 '학생부 항목별 워드파일검사'를 실행하고, 대상 폴더와 검사 패턴을 지정합니다.

올인원 도우미 기능
Step 3

📊 오류 보고서 추출

오류 부분이 노란색 하이라이트로 표시된 검사결과 워드 파일과 요약 엑셀 결과 보고서를 확인합니다. (※ 중요: 한글과컴퓨터 한워드가 아닌, 반드시 Microsoft Word(MS 워드) 프로그램으로 파일을 열어 작업합니다. 필요시 MS워드의 검토 - 맞춤법 기능 사용)

자동 리포트 확인
Step 4

✍️ 원본 파일 최종 수정

검출된 기재 금지 단어(수상, 유튜브 등)와 문법적 오류(1인칭 표현, 연속 공백 등)를 나이스에 최종 반영합니다.

최종 정정 반영

학생별로 분할된 PDF 파일들을 AI로 안전하고 신속하게 검사할 수 있도록 민감 정보(출력자, IP 등)를 선제 일괄 삭제한 뒤 DRM AI의 병렬처리 기법으로 검증하는 프로세스입니다.

Step 1

📄 학생별 PDF 파일 준비

나이스에서 분할 내려받기 하거나 'PDF 페이지 지정 분할'로 쪼갠 학급별/학생별 개별 PDF 파일들을 한 폴더에 깔끔하게 수집해 둡니다.

작업 대상 PDF 준비
Step 2

🛡️ 개인정보 일괄 삭제 실행

AI 검사 전 개인정보 및 출력 보안 노출을 선제 방지하기 위해, 올인원 도우미의 '개인정보 삭제 실행'을 적용하여 출력자 정보와 컴퓨터 IP 등을 일괄 제거합니다.

개인정보 제거 기능
Step 3

⚡ DRM AI 행단위 병렬 검사

개인정보가 정화된 PDF 경로가 정돈된 엑셀 데이터를 바탕으로, DRM AI의 제미나이 행단위 병렬처리 엔진을 구동해 학생부 기록 오류와 금지어를 일괄 분석합니다.

DRM AI 병렬 처리

6. DRM AI 설치 및 업데이트 방법 가이드

배포받은 압축 파일을 풀고 그 안의 DRM_AI_설치및업데이트.bat 을 더블클릭하면, 매크로 차단 해제 · 엑셀 신뢰 위치 등록 · 파이썬(Python) 설치 · 필수 패키지 설치 · 추가 기능 파일 복사까지 프로그램이 순서대로 처리합니다. 선생님께서 하실 일은 더블클릭 한 번과 화면 질문에 번호·Y/N 로 답하기가 전부이며, 약 10~30분 대부분이 기다리는 시간입니다. 중간에 멈추더라도 다시 더블클릭하면 안 된 부분부터 이어서 진행됩니다.

설치가 끝나면 처음 설치하시는 분만 엑셀에서 추가 기능을 [찾아보기]로 한 번 직접 등록하시면 완료됩니다. (설명서 4-1 에 화면 그대로 안내되어 있으며, 업데이트하시는 분은 이 과정도 필요 없습니다)

이 설명서는 특정 버전에 매이지 않고 앞으로 배포되는 모든 버전에 그대로 적용됩니다. 초보자 기준으로 서술되어 있으며, 화면에 나오는 오류 문구별 대처법과 완료 확인 체크리스트, 그리고 설치가 도중에 막혔을 때 직접 해결하는 방법까지 포함합니다.
